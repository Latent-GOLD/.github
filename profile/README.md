# Latent GOLD — Named classes in a survey you run

Latent GOLD keeps one named class model on the desk: the live groups, the mixture step in front of you, and a short note the next wave can read. Extra surveys wait for their own title.

## Session Card

| Slice | What you do in Latent GOLD | What remains |
|-------|------------------------|--------------|
| Arrival | Open Latent GOLD and name today's survey model | A titled class session |
| Focus | Keep only live groups on the Latent GOLD desk | A short class list |
| Check | Read the Latent GOLD summary before a large change | A confirmed mixture set |
| Handoff | Mark finished waves inside Latent GOLD | A note for the next wave |

## How Latent GOLD Sits

Latent GOLD does not replace the survey tool or the files you already keep. It sits beside them as a named analysis desk for one survey you run: which latent classes are open, which mixture is pinned, and what the next wave should read. A local Latent GOLD profile is enough for everyday grouping work.

If two people share a PC, each keeps a Latent GOLD style of their own. The class board stays small on purpose. Extra surveys wait for their own title instead of crowding the live mixture.

A first visit should be one short class model, then the same Latent GOLD desk the next day. That is enough to see if the grouping still holds on data you are allowed to analyze.

## Traffic Light

| Signal | On the Latent GOLD board | What you do |
|--------|----------------------|-------------|
| Green | Named model, short class list | Continue the same survey wave |
| Amber | Groups from two surveys mixed | Split the set before a large change |
| Red | No title, ad hoc clusters | Stop and name the Latent GOLD model first |
| Clear | Handoff written, classes few | Close Latent GOLD and leave the analysis desk |

## Open Order

1. Open the last Latent GOLD session, not a new empty model.
2. Read the class list and the last handoff.
3. Finish one visible mixture step inside Latent GOLD.
4. Write what changed, then close with fewer loose groups than you found.
5. If the set feels crowded, drop anything that belongs to a different Latent GOLD survey.

## After a Week

A new survey wave should reopen the same Latent GOLD model, not a fresh cluster guess. It is the same title, a shorter class list, and a note that still makes sense on Monday.

If every group is pinned, nothing stands out. Take finished waves off the live set so the next visit starts on the survey that is still open.

Other programs stay where they are. Latent GOLD only keeps the path back: model name, classes, summary, handoff. Leave Latent GOLD with a quieter analysis desk than the one you opened.

## Sign-off

- [ ] The Latent GOLD model name is short enough to scan
- [ ] Only live classes from a survey you run are pinned
- [ ] A second person can read the handoff
- [ ] The last Latent GOLD session still opens after a restart
- [ ] Finished waves are off the live Latent GOLD set
- [ ] The Latent GOLD summary still matches the classes on the desk

## Field Note

Latent GOLD is easier to reopen when the classes still belong to the survey you run. Name the model, keep the live groups, finish one visible mixture step, and write what changed. Extra surveys wait for their own title.

The same loop fits a new wave, a shared computer, or a class model you already named. Open the last Latent GOLD session and continue. Do not rebuild the groups from scratch.
